# Amazon Clone - Front End Project

A responsive Amazon clone website built with HTML, CSS, and JavaScript.

## Project Overview

This is a front-end clone of Amazon's website that includes:

- Home page with navigation and product categories
- Product listing page with search functionality
- Shopping cart functionality
- User authentication (login/signup pages)
- Responsive design that works on all devices

The project uses pure HTML, CSS, and JavaScript to create a modern e-commerce interface similar to Amazon's design.
